## Потоки обмена

**Крипта на крипту (5 шагов):**
Выбор валют → Ввод данных → Оплата → Обработка → Завершено

**Фиат на крипту (6 шагов):**
Выбор валют → Ввод данных → Верификация → Оплата → Обработка → Завершено

**Крипта на фиат (5 шагов):**
Выбор валют → Ввод данных → Оплата → Обработка → Завершено

**Наличные → Крипта (5 шагов):**
Выбор валют → Ввод данных → Бронирование → Визит в офис → Завершено

**Крипта → Наличные (5 шагов):**
Выбор валют → Ввод данных → Бронирование → Визит в офис → Завершено

**DEX обмен (4 шага):**
Подключение кошелька → Выбор токенов → Approve → Swap

При ошибке на этапе обработки — переход на страницу ошибки (4 шага: Выбор валют → Ввод данных → Оплата → Ошибка).

## Структура страниц

### index.html — Главная

**HEADER** — логотип, навигация (выпадающее меню "Обмен"), переключатели темы и языка, кнопки входа/регистрации.

**HERO SECTION:**
- Заголовок и подзаголовок
- Раскрывающиеся бейджи условий (фиксация курса, AML)
- Форма обмена: тип курса, поля "Отдаёте"/"Получаете" (сумма, валюта, сеть, лимиты), таймер обновления курса (60 сек), кнопка обмена

**SEO TEXT** — текстовый блок с описанием направления обмена.

**POPULAR DIRECTIONS** — сетка из 6 карточек с популярными парами обмена.

**EXCHANGE STEPS** — 4 шага обмена с иконками и описаниями.

**REVIEWS** — 4 карточки отзывов (аватар, имя, рейтинг, текст, направление).

**FOOTER** — 4 колонки (О компании, Сервисы, Информация, Поддержка), партнёры, SEO-перелинковка, копирайт.

### index-dex.html — Главная (DEX)

**HEADER** — вместо кнопок «Войти / Регистрация» — кнопка «Подключить кошелек».

**HERO SECTION:**
- Заголовок и подзаголовок (децентрализованный обмен, без KYC)
- Раскрывающиеся бейджи условий (тип обмена — децентрализованный, верификация — не требуется, мультисеть)
- Виджет обмена LI.FI: контейнер-плейсхолдер для встроенного виджета li.fi (подключается внешним скриптом). Показывает пояснение и область, куда будет рендериться виджет.

**SEO TEXT** — текст о DEX обмене, агрегаторе и поддерживаемых сетях.

**EXCHANGE STEPS (DEX)** — 4 шага: подключить кошелек, выбрать токены, Approve, Swap.

**REVIEWS** — 4 карточки отзывов о DEX обменах.

**FOOTER** — идентичен index.html, SEO-перелинковка: Swap Ethereum, Swap BNB Chain, Swap L2 Networks.

  - **Баланс проверок:** текущий баланс (доступно проверок), сводка списания (будет списано / останется), кнопка "Использовать проверку с баланса"

## Разметка wireframe

## Файлы

- `styles.css` — стили и CSS-переменные (цвета, шрифты, отступы, тени, тёмная тема)
- `script.js` — интерактивность (тема, язык, dropdown, бейджи, тип курса, тип карты, sidebar, фильтры, копирование, FAQ аккордеон)

- Переключатель темы (светлая/тёмная) — сохраняется в localStorage

## Адаптивность

- Desktop (>768px): двухколоночные layout, все метки шагов видны
- Tablet (768px–480px): двухколоночные layout сохраняются, шаги компактнее
- Mobile (<480px): одноколоночный layout, метки шагов скрыты кроме активного
