# Wireframe криптообменника

Структурный каркас страниц криптообменника. Показывает блоки, элементы и их расположение.

## Страницы

| Файл | Назначение |
|------|-----------|
| index.html | Главная страница с формой обмена |
| exchange-order.html | Оформление заявки (ввод данных) |
| exchange-card-verification.html | Верификация банковской карты (фиат-крипта) |
| exchange-identity-verification.html | Верификация личности через Sumsub (фиат-крипта) |
| exchange-payment.html | Оплата заявки |
| exchange-processing.html | Обработка заявки |
| exchange-error.html | Ошибка обмена |
| exchange-complete.html | Обмен завершён |

## Потоки обмена

**Крипта на крипту (5 шагов):**
Выбор валют → Ввод данных → Оплата → Обработка → Завершено

**Фиат на крипту (6 шагов):**
Выбор валют → Ввод данных → Верификация → Оплата → Обработка → Завершено

При ошибке на этапе обработки — переход на страницу ошибки (4 шага: Выбор валют → Ввод данных → Оплата → Ошибка).

## Структура страниц

### index.html — Главная

**HEADER** — логотип, навигация (выпадающее меню "Обмен"), переключатели темы и языка, кнопки входа/регистрации.

**HERO SECTION:**
- Заголовок и подзаголовок
- Раскрывающиеся бейджи условий (фиксация курса, AML)
- Форма обмена: тип курса, поля "Отдаёте"/"Получаете" (сумма, валюта, сеть, лимиты), кнопка обмена

**SEO TEXT** — текстовый блок с описанием направления обмена.

**POPULAR DIRECTIONS** — сетка из 6 карточек с популярными парами обмена.

**EXCHANGE STEPS** — 4 шага обмена с иконками и описаниями.

**REVIEWS** — 4 карточки отзывов (аватар, имя, рейтинг, текст, направление).

**FOOTER** — 4 колонки (О компании, Сервисы, Информация, Поддержка), партнёры, SEO-перелинковка, копирайт.

---

### exchange-order.html — Оформление заявки

**STEPS INDICATOR** — 5 шагов, шаг 2 активен.

**ORDER LAYOUT** (две колонки):
- Левая: форма (адрес кошелька, MEMO, email, Telegram, промокод, чекбокс согласия, кнопка)
- Правая: детали заявки (пара обмена, курс, сети, подтверждения, сумма, предупреждение)

---

### exchange-card-verification.html — Верификация карты

**STEPS INDICATOR** — 6 шагов, шаг 3 активен.

**VERIFICATION CARD** (по центру):
- Выбор типа карты (физическая / виртуальная)
- Область загрузки фото (drag & drop, PNG/JPG до 10MB)
- Требования к фото (динамически меняются от типа карты)
- Кнопка "Продолжить к оплате"

---

### exchange-identity-verification.html — Верификация личности

**STEPS INDICATOR** — 6 шагов, шаг 3 активен.

**VERIFICATION CARD** (по центру):
- Блок Sumsub (иконка, описание)
- Пошаговая инструкция (3 шага)
- Кнопка-ссылка "Перейти к верификации"
- Статус ожидания верификации
- Кнопка "Продолжить к оплате" (неактивна до прохождения)

---

### exchange-payment.html — Оплата

**STEPS INDICATOR** — 5 шагов, шаг 3 активен.

**PAYMENT LAYOUT** (две колонки):
- Левая: таймер обратного отсчёта, сумма к оплате (с копированием), адрес для отправки (с копированием), сеть, QR-код, кнопка "Я оплатил", предупреждение
- Правая: детали заявки (пара обмена, ID, курс, сети, подтверждения, сумма)

---

### exchange-processing.html — Обработка

**STEPS INDICATOR** — 5 шагов, шаги 1-3 завершены, шаг 4 активен.

**PROCESSING CARD** (по центру):
- Анимированный спиннер
- Текст: "Обрабатываем вашу заявку"
- Направление обмена (пара валют)
- Информация о заявке (ID, курс, сети, адрес, сумма)
- Сообщение: "Не закрывайте страницу"

---

### exchange-error.html — Ошибка

**STEPS INDICATOR** — 4 шага, шаги 1-3 завершены, шаг 4 "Ошибка" (красный, с иконкой X).

**ERROR CARD** (по центру):
- Красная иконка X в круге
- Текст: "Заявка не может быть выполнена"
- Блок причины ошибки (красная рамка)
- Направление обмена
- Информация о заявке (ID, статус "Ошибка")
- Кнопки: "Связаться с поддержкой", "Вернуться на главную"

---

### exchange-complete.html — Завершено

**STEPS INDICATOR** — 5 шагов, все завершены, шаг 5 с галочкой.

**COMPLETE CARD** (по центру):
- Зелёная иконка галочки в круге
- Текст: "Обмен успешно выполнен!"
- Направление обмена
- Информация о заявке (ID, статус "Завершено", TX Hash, итоговая сумма)
- Кнопки: "Новый обмен", "Вернуться на главную"

---

## Разметка wireframe

- Красные пунктирные рамки — блоки (`data-block` + `.block-label`)
- Голубые пунктирные рамки — элементы (`data-element` + `.element-label`)

## Файлы

- `styles.css` — стили и CSS-переменные (цвета, шрифты, отступы, тени, тёмная тема)
- `script.js` — интерактивность (тема, язык, dropdown, бейджи, тип курса, тип карты)

## Темы и язык

- Переключатель темы (светлая/тёмная) — сохраняется в localStorage
- Переключатель языка (RU/EN) — сохраняется в localStorage

## Адаптивность

- Desktop (>768px): двухколоночные layout, все метки шагов видны
- Tablet (768px–480px): двухколоночные layout сохраняются, шаги компактнее
- Mobile (<480px): одноколоночный layout, метки шагов скрыты кроме активного
