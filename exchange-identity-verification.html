Верификация личности

Для завершения обмена необходимо пройти верификацию личности. Процедура проходит через защищенный сервис Sumsub и занимает несколько минут.

Sumsub Header
Sumsub Identity Verification
Безопасная проверка через сертифицированного провайдера
Sumsub Steps
1
Подготовьте документ
Паспорт, водительское удостоверение или ID-карта
2
Перейдите по ссылке
Нажмите кнопку ниже для перехода на страницу верификации
3
Следуйте инструкциям
Загрузите фото документа и пройдите проверку лица
Info Message
Важно: Верификация проводится через защищенный сервис Sumsub. Ваши данные передаются по зашифрованному каналу и обрабатываются в соответствии с политикой конфиденциальности.
